# Атлас ароматов — требования и план реализации

Дата: 2026-09-11
Статус: реализовано (v1)

## Назначение

Личный справочник по эфирным маслам для собственного использования (не для клиентов wellness-платформы — это решение было принято явно в процессе брейнштормa). Задача: по симптому/запросу быстро находить подходящее масло, способ применения, разведение и меры безопасности.

## Требования

1. **Аудитория** — только для личного использования автора.
2. **Платформа** — веб-страница/мини-приложение, без бэкенда и подписок. Доступна и с телефона, и с компьютера.
3. **База масел**:
   - Весь текущий каталог doTERRA: единичные масла + фирменные смеси (blends).
   - Плюс 3 масла второго бренда — Kundalini Aroma: Пало Санто, Шалфей, Чампака.
   - Масла, которые реально есть в наличии у автора, помечаются флагом "в наличии" и фильтруются отдельно.
4. **Данные по каждому маслу**: русское/английское/латинское название, свойства и назначение, способ применения (ароматически / на кожу с разведением / внутрь — если официально разрешено), меры предосторожности (беременность, дети, животные, фотосенсибилизация).
5. **Безопасность контента** — заметный дисклеймер: это справочный материал, не медицинская консультация. Отдельно должны быть выделены "горячие" масла (обязательное разведение) и фотосенсибилизирующие цитрусовые.
6. **Обновляемость** — при появлении новых масел или изменении списка "в наличии" должно быть легко обновить данные без пересборки всего приложения вручную.
7. **Доступность после сессии** — инструмент не должен зависеть только от временной сессии/scratchpad-папки: нужна постоянная копия в самом проекте.

## Архитектура

Статическое веб-приложение без сборщика и фреймворков — весь объём данных (81 масло) и вся логика умещаются в вёрстку на чистом HTML/CSS/JS.

```
index.html              — страница: разметка, стили (CSS custom properties, светлая/тёмная тема), JS-логика
data/
  oils_data.js           — итоговый массив масел + общие правила безопасности, подключается как <script>
  raw/
    doterra_oils.json     — сырые данные по каталогу doTERRA (собраны через веб-исследование)
    kundalini_oils.json   — сырые данные по Kundalini Aroma
scripts/
  merge.js               — Node-скрипт: читает raw/*.json, проставляет флаги in_stock, пишет data/oils_data.js
```

**Почему так:** разделение "сырых исследованных данных" и "готового бандла для страницы" позволяет менять список масел в наличии или добавлять новые масла, редактируя только JSON, не трогая логику страницы.

## Компоненты страницы

- **Поиск** — по названию (RU/EN/латынь), тегам и тексту описания.
- **Фильтры-чипы** — по категориям (сон, стресс, иммунитет, боль, кожа, пищеварение, энергия, женское здоровье, дыхание), формируются динамически из данных.
- **Переключатель "Только мои масла"** — включён по умолчанию.
- **Карточка масла** — краткая сводка + пометка "в наличии" + маркер предупреждения, если масло "горячее" или фотосенсибилизирующее.
- **Детальный экран** — полная информация по маслу: свойства, ароматическое/кожное/внутреннее применение, блок мер предосторожности отдельным акцентным блоком; для смесей — состав с переходом к маслу-компоненту.
- **Экран "Общие правила безопасности"** — разведения, "горячие" масла, фотосенсибилизирующие цитрусовые, беременность/дети/животные, приём внутрь.
- **Дисклеймер** — постоянно видимая плашка под шапкой, с разворачиваемым полным текстом.

## Источники данных и оговорки

- Единичные масла и смеси doTERRA сверены с официальным сайтом doterra.com (Product Information Pages, страница по безопасности эфирных масел).
- Составы части смесей (Balance, Forgive, Console, InTune, Passion, Cheer, Elevation, HD Clear) — не всегда официально публикуемая рецептура, реконструированы из вторичных источников; помечать как ориентировочные.
- Данные по беременности для конкретных масел — общепринятые стандарты ароматерапии (doTERRA не публикует детальный список по беременности), а не официальная позиция производителя.
- "Клементин" добавлен вручную (нет в исследованном каталоге, но есть в коллекции автора).
- Бренд Kundalini Aroma не найден как отдельный источник в интернете — данные собраны по самим маслам (Пало Санто, Шалфей, Чампака) из общих ароматерапевтических источников. Для "Шалфея" оставлено явное предупреждение — нужно уточнить у производителя вид (обыкновенный шалфей vs шалфей мускатный), так как противопоказания различаются.

## Доставка

Два одновременных способа доступа:
1. **Локальные файлы в проекте** (этот репозиторий) — открывается двойным кликом по `index.html`, не зависит от сессии/интернета.
2. **Опубликованный Claude Artifact** (приватная ссылка) — для доступа с телефона без переноса файлов.

Оба должны обновляться синхронно при внесении изменений.

## Как обновлять (план на будущее)

1. Отредактировать `data/raw/doterra_oils.json` или `data/raw/kundalini_oils.json` (добавить масло, поправить текст) — либо список `inStockSingles`/`inStockBlends` в `scripts/merge.js`, если поменялась коллекция.
2. Выполнить `node scripts/merge.js` — пересоберёт `data/oils_data.js`.
3. Обновить локальный `index.html` (если менялась вёрстка/логика) и переопубликовать Artifact той же ссылкой.

## Не входит в v1 (сознательно отложено)

- Интеграция в wellness-платформу для клиентов (Bubble.io/Make.com) — отдельная задача, требует своего брейншторма при необходимости.
- Персональные заметки пользователя по маслам, сохраняемые между сессиями (localStorage/база данных артефакта) — не запрашивалось, можно добавить позже.
- Проверка `in_stock`/составов смесей по фактическим этикеткам бутылок — рекомендовано автору сделать точечно для масел с пометками "проверить" (см. safety_notes отдельных записей).
