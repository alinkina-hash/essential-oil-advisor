# Атлас ароматов

Личный справочник по эфирным маслам doTERRA и Kundalini Aroma: поиск по симптомам, способы применения, разведение и меры предосторожности.

## Как открыть

Двойной клик по `index.html` — откроется в браузере. Файл `data/oils_data.js` должен лежать рядом (в папке `data/`), иначе страница будет пустой.

Веб-версия (та же страница, доступна с телефона): https://claude.ai/code/artifact/2805e9b4-c84f-4ed0-bc51-ff18962c5c18

Список источников виден прямо на странице (кнопка «Источники» в шапке) и дублируется в `docs/sources.md`.

## Структура проекта

```
index.html              — сама страница (вёрстка, стили, вся логика)
data/
  oils_data.js            — итоговые данные, которые загружает index.html
  raw/
    doterra_oils.json      — сырые данные по каталогу doTERRA (57 масел + 20 смесей)
    kundalini_oils.json    — сырые данные по 3 маслам Kundalini Aroma
    kalmykova_notes.json   — заметки травницы Светланы Калмыковой (личный опыт, гормоны, антипаразитарные протоколы)
    additional_oils.json   — 19 растений/масел, упомянутых Светланой, но не входящих в каталог doTERRA/Kundalini (аир, пижма, полынь, витекс, ваниль и др.) — добавлены целиком, включая редкие/спорные по безопасности
    sources.json           — ссылки на источники (та же кнопка «Источники» на странице)
scripts/
  merge.js               — пересобирает data/oils_data.js из data/raw/*.json
```

Итого в каталоге 100 позиций (78 doTERRA + 3 Kundalini Aroma + 19 дополнительных растений от Светланы), из них 37 отмечены «в наличии».

## Как обновить

**Изменить список масел «в наличии»** — открой `scripts/merge.js`, поправь списки `inStockSingles` / `inStockBlends` (id масел смотри в `data/raw/*.json`), затем выполни:

```
node scripts/merge.js
```

**Добавить/поправить масло** — отредактируй нужный объект в `data/raw/doterra_oils.json` или `data/raw/kundalini_oils.json`, затем снова `node scripts/merge.js`.

После пересборки просто обнови страницу в браузере (для локального файла) — правки применятся сразу.

## Источники информации на странице

На странице три явно разделённых источника:
- **Официальные данные doTERRA** — свойства, применение, разведение, меры безопасности по каждому маслу, раздел «Общие правила безопасности».
- **Заметки травницы (Светлана Калмыкова)** — личный опыт и авторские протоколы из материалов её курсов (не официальная позиция doTERRA и не научные данные). Показаны отдельным фиолетовым блоком на карточках соответствующих масел и на отдельной странице «Заметки травницы» — там же таблицы «гормон → масла» и антипаразитарные протоколы (замасливание, полоскание рта и т.д.).
- **Дополнительные растения не из каталога doTERRA** (брендовая пометка «Ароматерапия (не doTERRA)») — 19 масел, которые упоминает Светлана, но которых нет у doTERRA/Kundalini Aroma. Данные по применению/дозировке/безопасности для них собраны из общих ароматерапевтических источников (не от Светланы и не от doTERRA). Часть из них по данным исследования — не типичные паровые эфирные масла (например, ним и ваниль — на деле масло-носитель и абсолю/CO2-экстракт), это явно помечено на карточке блоком «Важно про этот продукт». У нескольких (аир, полынь, обычная пижма) — серьёзные противопоказания вплоть до рекомендации не использовать без ароматерапевта.

## Важно

Это справочный материал для личного использования на основе открытых источников — не медицинская консультация. Часть данных (составы некоторых блендов doTERRA, рекомендации при беременности) — это общепринятые стандарты ароматерапии, а не официальная позиция производителя, так как компания не публикует эти детали. Подробности — в разделе «Общие правила безопасности» на самой странице.
